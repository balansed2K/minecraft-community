MINECRAFT COMMUNITY — ПРОСТОЕ РЕДАКТИРОВАНИЕ

1. КАК ЗАПУСТИТЬ
Распакуйте ZIP и откройте index.html.

2. КАК МЕНЯТЬ ФОТОГРАФИИ ДОМОВ
Откройте папку:
assets -> houses

Там находятся:
house-1.png
house-2.png
...
house-8.png

Чтобы заменить дом, просто замените нужный файл своей фотографией и сохраните ТО ЖЕ ИМЯ.
Например: новую фотографию первого дома назовите house-1.png.

3. КАК МЕНЯТЬ НАЗВАНИЕ, ЭТАЖНОСТЬ И ЦЕНУ
Откройте файл:
site-settings.js

В самом начале есть блок «НАСТРОЙКИ САЙТА».
Меняйте только текст между кавычками.
Например:
{name: 'Дом №1', floors: '1 этажный', price: 'Договорная', image: 'assets/houses/house-1.png'}

Можно сделать:
{name: 'Большой коттедж', floors: '2 этажный', price: '500 ₽', image: 'assets/houses/house-1.png'}

4. КАК МЕНЯТЬ ГЛАВНЫЙ ЗАГОЛОВОК
В site-settings.js найдите:
heroTitle: 'СТРОЙ СВОЁ\nБУДУЩЕЕ'

Замените текст внутри кавычек.
Символ \n означает перенос строки.

5. КАК МЕНЯТЬ ПОДЗАГОЛОВОК
Найдите:
heroSubtitle: 'Твой Minecraft-мир. Твои идеи. Твои постройки.'

6. КАК МЕНЯТЬ DISCORD
Найдите:
discordUrl: 'https://discord.com/'

и вставьте приглашение своего Discord-сервера.

7. ПОСЛЕ ИЗМЕНЕНИЙ
Сохраните файл site-settings.js, затем обновите страницу сайта (Ctrl + F5).

ВАЖНО:
Не удаляйте кавычки, запятые и названия полей. Меняйте только значения внутри кавычек.

Отзывы сейчас сохраняются в браузере конкретного пользователя. Чтобы отзывы были общими для всех игроков, позже понадобится серверная база данных.
